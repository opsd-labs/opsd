# 安全说明

## 安全入口

控制台地址包含初始化时生成的随机安全入口：

```text
https://hub.example.com:65535/{安全入口}/
```

安全入口用于减少被扫描和误访问，不是认证机制。即使入口正确，仍需要登录、会话 Cookie、CSRF 和 Origin 校验。

修改安全入口后，旧地址失效，已有会话有短暂宽限。不要把入口写入公开日志、截图或聊天记录。

## Agent 注册例外

Agent 在取得客户端证书前无法使用 mTLS，因此 `POST /api/v1/enroll` 只存在于独立临时 HTTPS 监听。该监听仅在至少一枚一次性注册令牌有效期间开放，不提供控制台或其他 API；令牌消费、撤销、到期后关闭，重启时由持久状态恢复。已注册 Agent 的 mTLS WSS 通道保持开放。注册使用十分钟有效令牌，并要求 Agent 校验 Hub CA 指纹。

这条路径会暴露服务存在性。另有三个精确的只读输出路径 /api/v1/public/nodes、/api/v1/public/summary、/api/v1/public/metrics，使用独立 Bearer API Key。不要扩大为模糊前缀或向这些路径开放管理能力。

## CA 和 TLS

初始化输出 CA 指纹，并在数据目录生成 CA 和 Hub 身份材料。部署时：

- 通过可信渠道分发 CA；
- 在浏览器和 Agent 侧核对指纹；
- 保持 TLS 证书校验开启；
- 保护 CA 私钥、Hub 私钥和 Agent 身份材料；
- 不把 `.pem`、`.key`、令牌或密码文件提交到 Git。

## 反向代理

反向代理必须：

- 保留完整安全入口路径；
- 传递正确的 Host、Origin 和 HTTPS 信息；
- 不重写掉入口层；
- 不把 Agent mTLS 通道降级为普通 HTTP；
- 不公开仅供容器健康检查使用的 `65534` 端口。

## 权限和秘密

- 管理员密码文件使用 `0600` 权限，并在初始化后移除。
- Agent 注册令牌只保存到 `0600` 文件，使用一次后删除。
- 节点数据库凭据继续留在节点既有的权限受限文件中。
- Hub 不挂载 Docker socket。
- 只读输出使用独立密钥、节点范围与字段白名单，不返回内部地址、线路、插件秘密或管理会话。
- 插件包具有执行权限，只安装可信程序。配置与秘密分开存储，浏览器不读取秘密原文；节点服务私钥不上传 Hub。
- Portainer 普通 Agent 使用其原生自签名 TLS 与共享密钥，不能把它等同于 OPSD mTLS；服务端证书及 ET 绑定边界见 [架构说明](architecture.md)。

## 防火墙能力

自动互信只管理 OPSD 归属规则，保留其他规则和默认策略；ET 网段同时限制入接口。撤销 OPSD 身份不隔离整个 ET 网络。现代 firewalld 独占表当前会拒绝写入。

通用防火墙策略管理的默认构建仍禁止生产写入。`experimental-firewall` 只能在隔离实验室中使用，并且必须有独立网络命名空间、回滚验证和完整故障矩阵。

WSL2 与宿主机共享内核，不能替代独立 Linux 内核的防火墙生产验收。当前版本不应在真实生产节点上启用该特性。
