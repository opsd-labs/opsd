# 提取记录（不是契约）

本目录下的 JSON 是 2026-09-24 编写 [`../openapi.yaml`](../openapi.yaml) 时，从 `src/` 逐模块
提取的接口事实，每个端点带 `文件:行号` 证据。

**它不是契约，不参与构建，也不要在这里改接口。** 契约是 `../openapi.yaml`；
改接口请按 [`../README.md`](../README.md) 的步骤走。

保留它的唯一理由是让评审能回查某个字段是从哪一行源码得来的。源码一旦演进，
这里的记录就会过时——有疑问时以 `openapi.yaml` 和源码为准。

## 文件与负责的接口

| 文件 | 覆盖 |
|------|------|
| `api-core.json` | 节点目录、节点更新/撤销、注册令牌、地址集合、注册、续期、验证、安全入口 |
| `api-tasks.json` | 节点操作提交、任务列表/详情、任务事件、事件 SSE、结构化文件操作 |
| `auth-audit.json` | 登录/登出/会话、审计查询，以及 Cookie/CSRF/Origin/限流的横切约定 |
| `channel-metrics.json` | 会话流（WebSocket）、指标总览/状态/历史 |
| `share-admin.json` | 分享设置、令牌与密钥管理 |
| `share-public.json` | 分享页面、静态资源、页面数据与公开机器接口 |
| `theme.json` | 主题列表/激活/上传/删除，分享主题包与资源 |
| `storage.json` | 存储预检、主机盘点，存储集群定义/计划/执行/状态/桶/用户 |
| `database.json` | 数据库只读巡检总览与下发 |

编写完成后这些记录经过一次多模型交叉审计（对照源码逐条核对），据此修正了 12 处
事实性偏差；审计过程没有回写到这里，修订结果只在 `openapi.yaml` 里。
