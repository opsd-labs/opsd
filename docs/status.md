# 项目状态

状态更新时间：2026-10-06。

本文只说明当前仓库可以证明的状态，不把“代码存在”或“单元测试通过”自动解释为生产就绪。

## 状态定义

| 标记 | 含义 |
| --- | --- |
| 已实现 | 代码、接口和基础自动化验证已存在，但仍可能需要环境验证 |
| 部分验证 | 已完成解析、单元或集成层验证，真实节点/集群场景未覆盖 |
| 实验性 | 只能在隔离实验室中使用，不作为生产承诺 |
| 未完成 | 尚未达到当前版本的生产验收要求 |

## 验证边界

以下验证不能替代生产验收：

- 前端演示数据不能代表生产实时盘点；
- 单元测试不能证明真实发行版、内核或权限配置正确；
- WSL2 共享宿主机内核，不能证明独立 Linux 内核下的防火墙行为；
- OpenAPI lint 和类型生成不能单独证明 HTTP 实现正文与错误状态完全一致；
- 本地 Docker smoke test 不能证明真实节点网络、证书和反向代理配置正确。

## 发布前至少需要补齐

- 真实 Linux 节点上的指标、主机盘点和数据库巡检验证；
- 真实多节点低影响试点以及连续观察；
- 独立 Linux 内核下的防火墙发现、写入、回滚、转发和连接跟踪矩阵；
- 独立 MariaDB 模式的真实回归；
- 异机恢复、磁盘损坏和备份介质故障演练；
- 生产反向代理、证书轮换和秘密分发流程。

在这些项目完成前，请把 opsd 视为开发/灰度阶段软件，而不是完整生产发行版。
