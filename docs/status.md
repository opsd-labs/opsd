## 验证边界

本批实现与当前 CI 证据集中见 [架构说明](architecture.md#本批云端证据与边界)。核心网络、三插件、只读输出和旧入口迁移已完成源码与云端验收；没有部署 C091、发布正式插件包或进行真实磁盘／四节点 Silo 验收。既有安装链四组合的历史记录继续见 [Agent 一键安装](agent-installation.md)。

以下验证不能替代生产验收：

- 前端演示数据不能代表生产实时盘点；
- 单元测试不能证明真实发行版、内核或权限配置正确；
- WSL2 共享宿主机内核，不能证明独立 Linux 内核下的防火墙行为；
- OpenAPI lint 和类型生成不能单独证明 HTTP 实现正文与错误状态完全一致；
- 本地 Docker smoke test 不能证明真实节点网络、证书和反向代理配置正确。

## 发布前至少需要补齐

- 真实 Linux 节点上的指标、主机盘点和数据库巡检验证；
- 真实多节点低影响试点以及连续观察；
- 自动互信的生产发行版与规模试点，以及通用防火墙策略的回滚和连接跟踪矩阵；
- 独立 MariaDB 模式的真实回归；
- 异机恢复、磁盘损坏和备份介质故障演练；
- 生产反向代理、证书轮换和秘密分发流程。

在这些项目完成前，请把 opsd 视为开发/灰度阶段软件，而不是完整生产发行版。
