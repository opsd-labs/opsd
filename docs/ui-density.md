# 高密度工作台与通用组件

## 设计基线

采用**中性底 + 局部靛蓝强调**。中性色承载内容，强调色只用于当前导航、主要操作与选中态。
令牌定义在 `web/src/style.css`，与 `docs/ui/design-study.html` 的 `themeFor()` 同源——修改任一处都应同步另一处。

| 项目 | 规格 |
|---|---|
| 正文 / 辅助文字 | 13px / 12px |
| 数据行 | 36px（移动端 40px） |
| 桌面控件 | 28px（移动端 40px） |
| 页面外边距 | 16px（表格页底部 8px，把高度让给数据行） |
| 区块间距 | 8px |
| 内容左右内边距 | 18px |
| 顶栏 / 侧栏 | 48px；侧栏 168px，可收起为 48px |
| 圆角层级 | 控件 6px、导航 8px、内容面 12px、弹层 16px |
| 表头 | 30px，默认每页 50 条，固定表头 |

浅色为默认，深色由 `data-theme` 覆盖；`system` 跟随系统。令牌取值：

| 令牌 | 浅色 | 深色 |
|---|---|---|
| 页面底色 | `#F4F5F7` | `#171A1F` |
| 内容面 | `#FFFFFF` | `#1D2229` |
| 浮层 | `#FFFFFF` | `#252B34` |
| 正文 | `#202732` | `#E7ECF3` |
| 辅助文字 | `#586272` | `#A6AFBD` |
| 靛蓝强调 | `#0F2540` | `#9BB5D6` |

状态语义色：positive 浅 `#2D6D4B` / 深 `#A8D8B9`，warning 浅 `#825917` / 深 `#DDB477`，
danger 浅 `#9F353A` / 深 `#EFA6A6`。轻底色由语义色与内容面按比例混合生成（浅色 7%、深色 12%）。
**所有普通文字对比度不低于 4.5:1**；实测最低为浅色状态标签的 5.6:1。

## 信息表达

同一信息在不同位置必须用同一种表达方式。判定与格式化集中在 `web/src/resourcePresentation.ts`，
列表与详情共用，业务页面不得自行拼装。

- **状态**：轻底标签，高 22px、圆角 6px，由文字 + 符号 + 语义色三者共同表达，灰度下仍可区分。
  符号表见 `components/ui/marks.ts`。
- **判定优先级固定为**：离线快照 > 未知 > 具体状态。「未知」是独立态，不得归入「已停止」或成功。
  地址同步在离线时保留「离线 · 待同步」，因为快照与待同步是两件事。
- **归属**：中性细边静态标签。`opsd` 表示受管，`Docker · 系统` 表示容器运行时自有，
  其余来源一律标注「· 只读」，缺省为「维护来源未知」。
- **端口**：Docker 显示 `8080 → 80 · TCP`，宿主机端口为主、容器端口与协议为次，
  具体绑定地址才显示、通配绑定留在 `title`；防火墙把端口作为主要数值、协议作为辅助标识，
  `any` 统一显示为「全部」。**解析失败必须保留原文**，不得伪造结构化映射；原文仍可被搜索。
- **动作**：防火墙的「允许」用绿色文字但不使用执行成功勾号；「丢弃／拒绝」是预期策略，
  使用中性阻断标记；红色只留给失败与冲突。

## 组件边界

- `web/src/components/ui`：按钮、输入、选择、复选框、状态标签、归属标签、端口、提示、页签、菜单、帮助、抽屉。全部使用 `style.css` 中的令牌。菜单、帮助及抽屉由 Reka UI 提供交互基础。
- `web/src/components/resources`：工具栏、状态栏、数据表、分页、字段表单、字段详情和变更对比。通过属性接收数据，不读取 API 或工作台状态。
- 业务页面与业务组件负责资源适配、任务语义和事件处理。`workspace.ts` 维护节点选择、会话、刷新订阅、表单和任务操作；`App.vue` 只装配。
- 容器会话独立于页面和抽屉内容生命周期。收起时保留终端 DOM 和 WebSocket，只有结束会话或退出应用才销毁；终端模块按需加载。

数据表通过 `rows`、`columns`、`rowKey` 接收资源，列插槽负责业务展示；`search` 和可排序列在当前已获取结果内工作，默认每页 50 条。`loading`、`error`、`unknown`、无资源和无匹配分别展示。分页不冒充后端分页。跨节点行键包含节点和资源身份。

抽屉详情默认 480px，配置和差异 720px，终端为宽抽屉。表单错误留在抽屉内，关闭后恢复触发位置的焦点；临时禁用提交按钮不会丢失键盘操作位置。

## 导航与页面

一级菜单固定为七项：**控制台、节点、数据库、容器、防火墙、存储、设置**。

任务不占用一级入口，改由顶栏任务面板承载，各资源页内保留自己的记录视图。
容器会话在顶栏提供入口，收起后仍可从顶栏重新打开。

- **控制台**：所有节点状态表 + 集群概览 + 「需要关注」聚合（离线、读取失败、异常任务）。
  指标列区分四种状态：**未上报指标**（Agent 无采样能力）、**尚未上报**、**采集失败**、**数据陈旧**。
  数值列在无采样时显示「—」，**绝不显示 0**。
- **节点**：列表 + 选中后展开的指标详情（曲线、汇总、挂载点、网络接口）。区间 1 小时到 30 天可选。
- **节点 / 容器 / 防火墙 / 存储 / 数据库**：紧凑汇总栏 + 资源表，具体节点详情与操作在选中节点后展开。
- 容器列表在全部环境视图保留节点列，选中单节点后省略节点列与 Stack 列（Stack 归属进详情）。

## 曲线绘制

`components/resources/MetricsChart.vue` 用内联 SVG 手绘，不引入图表库。分段逻辑在
`resourcePresentation.ts` 的 `segmentSeries`：相邻点间隔超过两倍步长即为断档，段与段之间不连线。

**缺失值必须显式跳过**：`Number(null)` 是 `0`，只判断 `Number.isFinite` 会把缺失画成真实的零。
所有取值统一走 `finiteNumber()`，这是「不补零」这条约束的唯一落点。

## 开发样板与验证

开发服务启动后访问 `http://127.0.0.1:5173/?demo=1&components=1`。样板页不出现在正式导航，也不打包到生产入口。

演示包含十二节点、每节点 60 条规则、长 IPv6、长镜像名、离线、已停止、异常、冲突及读取失败。
文档示例地址和服务均不是生产实况，演示模式不会发起变更请求。

**实测（1440×900、100% 缩放、深色）**：防火墙规则首行顶部 **215px**，单行 **36px**，
首屏完整可见 **18 行**。表头 30px，分页 28px。

验证命令：

```powershell
npx vue-tsc -b --force     # 类型检查，noEmit
npx vitest run             # 纯函数单元测试（src/**/*.test.ts）
npm run build              # 生产构建
npx playwright test        # 浏览器回归，tests/ 由 Playwright 收集
```

`vite.config.ts` 把 vitest 限定在 `src/**/*.test.ts`，避免它误收集 Playwright 用例。
TypeScript 设置 `noEmit`，避免在源码目录生成同名 JavaScript 干扰模块解析。

参考截图位于 `docs/ui/`：`console-{light,dark}.png`、`docker-dark.png`、
`firewall-{light,dark}.png`、`firewall-mobile.png`、`node-metrics-dark.png`、
`database-{light,dark}.png`、`nodes-{light,dark}.png`、`share-{light,dark}.png`。

截图可以随时重生成（需要先起开发服务器）：

```powershell
node web/tests/shots.mjs database      # 默认写到 docs/ui/{页面}-{light,dark}.png
node web/tests/shots.mjs nodes
```
